# Shopify App Store — listing FeedPlug

Document de référence pour la soumission Shopify App Store. À utiliser tel
quel dans Shopify Partners Dashboard → ton app FeedPlug → **App listing**.

> **Source de vérité** : ce fichier. Quand tu mets à jour le listing dans Partners,
> reflète les changements ici (commit + PR), sinon la prochaine soumission divergera
> et tu perdras du temps en correctifs review.

```

## 💰 Pricing display (Shopify App Store affiche automatiquement les Managed Pricing plans)

Les 4 plans sont déjà configurés dans Partners → Distribution → Managed Pricing
(`starter`, `pro`, `business`, `premium`). **Ne pas dupliquer** le pricing dans
la fiche App Listing : Shopify l'extrait directement de la config Managed
Pricing.

⚠️ Vérifier que les plans sont en statut **Published** avant la soumission.

## 🖼️ Assets visuels (checklist précise — ce que tu dois produire)

> Specs officielles : https://shopify.dev/docs/apps/launch/app-store/app-store-listing-guidelines

### App icon

- **1 fichier** : `app-icon.png`
- **Dimensions** : **1200 × 1200 px** (carré)
- **Format** : PNG, fond transparent OK, < 1 Mo
- **Style** : reconnaissable au 32×32 (Shopify l'affiche partout en miniature),
  pas de texte (le nom est déjà sous l'icon), pas de bordure (Shopify applique
  son propre masque coins arrondis)
- **Recommandation** : reprendre le mark FeedPlug existant en `frontend/src/app/icon.png`
  mais en 1200×1200 avec un peu de padding (10% de marge interne).

### Feature banner (hero)

- **1 fichier** : `feature-banner.png`
- **Dimensions** : **1920 × 1080 px** (16:9)
- **Format** : PNG ou JPG, < 1 Mo
- **Contenu** :
  - À gauche (tier gauche) : le titre du produit "Sync your catalog to
    Google Shopping, Bing & Amazon — in real time" + un sous-titre
    "Embedded for Shopify. Made for serious sellers." + un petit logo FeedPlug
  - À droite (deux tiers droits) : screenshot composite de l'app embedded —
    home avec "Plan Pro active" + diagnostic montrant des produits, avec
    un effet de Shopify Admin autour (chrome Shopify visible)

### Screenshots (minimum 3, recommandé 5, maximum 6)

Specs : **1600 × 900 px** chacun (16:9), PNG, < 2 Mo.

| # | Page à screenshoter | Caption (à coller dans Partners, ≤120 chars) |
|---|---|---|
| 1 | `/embedded` (home) avec une subscription PRO active | "Embedded home — manage your subscription and channels from Shopify Admin." |
| 2 | `/embedded/diagnostic` avec ≥10 produits scorés (idéalement quelques en `critical`) | "Quality diagnostic shows exactly which products Google will reject and why." |
| 3 | `/embedded/billing` avec la grille de 4 plans visibles | "Transparent Managed Pricing. No card to enter — billed through Shopify." |
| 4 | `/embedded/sources` avec ≥10 produits dans la table | "Real-time catalog sync. Every Shopify update lands on Google in <10s." |
| 5 | `/embedded/lia` avec ≥3 stores et inventory populated | "Local Inventory Ads: per-store stock, ready-to-paste feed URL for GMC." |

**Notes prises de screenshots** :
- Désactiver les notifications dans Shopify Admin avant la capture
- Utiliser un compte test propre (pas le compte personnel, pas victor@…)
- Locale `en-US` par défaut pour les screenshots (le marché App Store est global)
- Faire aussi une version FR (5 screenshots) qu'on uploadera dans la locale FR

### Demo video (60 secondes max — recommandé non obligatoire mais énorme lift de conversion)

- **1 fichier** : `feedplug-demo-60s.mp4`
- **Dimensions** : **1920 × 1080 px** (1080p)
- **Durée** : **45-60 secondes max** (Shopify recommande 60s, mais 45-50s convertit mieux)
- **Format** : MP4 H.264, < 50 Mo, audio facultatif (sous-titres FR+EN recommandés)
- **Script proposé** (45s) :

```
00:00–05  Shopify Admin → Apps → click FeedPlug
05–10    Home embedded : "Plan Pro active, Diagnostic, 2 channels"
10–18    Click Diagnostic → "47 products will be rejected, top reason: GTIN missing"
18–25    Click "Fix" sur un produit → ouvre Shopify Admin product editor
25–32    Retour à FeedPlug → click Catalog → "4,237 products synced, last sync 12s ago"
32–40    Click Billing → "Pro plan, $79/month, next renewal Aug 15"
40–45    Outro : logo + "feedplug.com / Built for Shopify"

Outils : Loom (gratuit, suffit pour MVP), Descript (pour les sous-titres),
ou contracter un freelance Fiverr "Shopify app demo video" si tu veux un
résultat très propre (compter $200-400, livré sous 5 jours).

## 📝 Reviewer notes (champ "Notes to reviewer" dans Partners)

Coller ce texte dans le champ `Notes to reviewer` — il facilite la review BFS :

```
=== FeedPlug review notes ===

App version: see latest git tag on the shopify/app-store-foundation branch.

Test merchant credentials :
  - Shop : feedplug-demo.myshopify.com  (development store with sample
    products already synced + a Pro subscription test-charged)
  - Login : reviewer-shopify@feedplug.com / [provided separately by email]

What to test :
  1. Install FeedPlug from this listing.
  2. App opens in Shopify Admin at /apps/feedplug/embedded with a clear
     home, a "Choose a plan" CTA and a NavMenu.
  3. Click "Choose a plan" → 4 plans grid → click "Choose Pro" → redirected
     to Shopify Managed Pricing approval screen (test charge mode in dev
     store, no real billing).
  4. After approval → back to embedded home, "Pro plan active" badge.
  5. Click "Diagnostic" → quality dashboard with bucketed scores and top
     rejection reasons. Click "Fix" on a product → opens Shopify Admin
     product editor in a new tab (target=_top).
  6. Click "Catalog" → 20 most recently updated products. "Sync now"
     triggers a re-ingestion (visible in lastSync timestamp ~10s later).
  7. Click "Local stores (LIA)" → create a store, upload the provided
     sample CSV, see inventory listed, copy the GMC feed URL.

Localization :
  - Default UI language is English (Shopify App Store default audience).
  - Set ?locale=fr-FR in the URL or sign in with a French Shopify Admin
    locale to see the French version.

Mandatory Shopify GDPR webhooks :
  - customers/data_request : acknowledged + logged for audit (no customer
    data is held, see Privacy Policy).
  - customers/redact : acknowledged + logged.
  - shop/redact : cascades FeedItem → Feed → FeedSource → Credential
    deletion. Triggered 48h after uninstall.

Product webhooks (real-time sync) :
  - products/create | products/update | products/delete : routed in
    server-minimal.js to ingestShopifyProductFromWebhook (incremental) or
    a full re-sync for deletes. Confirmation log in Cloud Run :
    "✅ Shopify webhook products/update: sync applied for {shop}".

Privacy & data :
  - Only Shopify scope requested : read_products.
  - No customer data, no orders, no payment info from the Shopify store.
  - Hosted on Google Cloud europe-west1 (Belgium). Application-level
    encryption (AES-256-GCM) on stored Shopify access tokens.

Contact for review questions : support@feedplug.com (Victor Soldet, founder).
Response time during review : < 4 hours on business days.
```

## 🚨 Pré-flight checklist avant soumission

À cocher dans l'ordre :

- [ ] Société immatriculée et raison sociale mise à jour dans :
  - [ ] `frontend/src/app/[locale]/(marketing)/legal/privacy/page.tsx` (`DATA_CONTROLLER_NAME`)
  - [ ] `frontend/src/app/[locale]/(marketing)/legal/terms/page.tsx` (`PROVIDER_NAME`)
  - [ ] `frontend/src/app/[locale]/(marketing)/legal/mentions/page.tsx` (`PUBLISHER.legalName` + adresse + RCS + capital + TVA)
- [ ] Privacy policy publique en FR + EN — déjà déployé sur `feedplug.com/{fr,en}/legal/privacy` ✅
- [ ] Terms publiques en FR + EN — déjà déployé ✅
- [ ] Mentions légales publique — déjà déployé ✅
- [ ] Support email (`support@feedplug.com`) actif et monitoré
- [ ] App icon 1200×1200 produit
- [ ] Feature banner 1920×1080 produit
- [ ] 5 screenshots 1600×900 produits (EN + FR)
- [ ] (Recommandé) Démo vidéo 45-60s produite
- [ ] Reviewer test merchant créé (dev store FeedPlug-demo) avec :
  - Catalogue de ~20 produits importés (mix scores : quelques `critical`, quelques `ok`)
  - 1 store LIA créé et inventory uploaded
  - Subscription Pro active (test charge)
  - Login reviewer-shopify@feedplug.com créé avec mdp aléatoire
- [ ] Reviewer notes finalisées (voir section ci-dessus)
- [ ] `SHOPIFY_BILLING_FORCE_TEST=true` **RETIRÉ** de Cloud Run env vars
  (sinon Shopify refusera la soumission car aucune charge réelle ne peut être faite)
- [ ] Webhooks `products/*` poussés dans Partners (`shopify app deploy`)
- [ ] Test approbation réelle effectuée sur dev store avec carte Bogus
- [ ] PR #1 mergée dans `fix/pre-launch-blockers` puis `fix/pre-launch-blockers` mergée
  dans `main` (ou simplement push direct main si la team ne fait pas de PR)
- [ ] Tag git `v1.0.0-app-store` posé sur le commit de soumission (pour
  retrouver facilement la version qu'a vue le reviewer en cas de question)

Quand toutes les cases sont cochées : Partners → App listing → **Submit for review**.

## 📅 Timeline review estimée

D'expérience (compte Partners 2026, 1re app) :
- **Day 0** : Submit
- **Day 2-5** : 1re review (souvent rejet pour 1-2 points cosmétiques ou de
  doc)
- **Day 6-8** : Corrections + re-submit
- **Day 9-14** : Approval & listing live

**Total** : compter ~2 semaines entre 1re soumission et live sur App Store.
Si tu vises une date précise (lancement campagne, salon, etc.), prévoir
3 semaines de marge.

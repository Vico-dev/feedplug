## 🎯 Score FeedPlug 0-100

### Formule de Calcul
```javascript
Score Global = 
  Titre (0-100) × 30% +
  Description (0-100) × 25% +
  Images (0-100) × 25% +
  Technique (0-100) × 20%
```

### Breakdown Détaillé

**Score Titre (30%)**:
- Longueur optimale 50-150 caractères : 30 pts
- Marque présente : 20 pts
- Attributs clés (couleur, taille, etc.) : 30 pts
- Pas de répétitions : 20 pts

**Score Description (25%)**:
- Longueur optimale 500-2000 caractères : 25 pts
- Structure bullet + paragraphe : 25 pts
- Mots-clés pertinents : 20 pts
- Marque mentionnée : 15 pts
- Pas de keyword stuffing : 15 pts

**Score Images (25%)**:
- Au moins 1 image : 40 pts
- Fond blanc : 20 pts
- Taille optimale 800x800+ : 20 pts
- Images multiples (3+) : 20 pts

**Score Technique (20%)**:
- GTIN ou MPN présent : 40 pts
- google_product_category : 30 pts
- Tous attributs remplis : 30 pts

### Recommandations Automatiques

Si score < 70 : 
```
⚠️ Produit à optimiser
Recommandations:
1. [HIGH] Optimiser le titre avec IA (+25-40 points)
2. [HIGH] Générer description optimisée (+30-50 points)
3. [MEDIUM] Compresser les images (+10-20 points)
```

```bash

    "itemId": "cdeda792-1e92-4e61-aac9-fc4f5c73f69d",
    "platform": "GMC",
```
